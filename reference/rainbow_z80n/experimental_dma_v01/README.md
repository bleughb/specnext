# Experimental Rainbow Islands sky DMA v0.1 downloads

- [Complete NEX bundle](rainbow_sky_dma_v01.zip): blitter, no-blitter, CPU-only and diagnostic game builds, hashes, instructions and software validation.
- [Separate NXC patch](rainbow_sky_dma_v01_blitter.nxc): reconstructs the blitter game build from the matching original `rainbow.z80` (MD5 `4c98b980b1726af545fccc99665ef29b`). NXC round-trip reconstruction matches the delivered NEX byte for byte.

The NXC is separate from the ZIP. The ZIP is unchanged from the original delivery; its README describes the original delivery location. These files are now hosted here at the owner's request. Pinned releases remain unchanged.

Use the SHA-256 sidecars to verify downloads. These are experimental builds; hardware timing, sound, interrupt, pacing and visual checks remain. Software evidence and build hashes are in [validation notes](../../../docs/rainbow_dma_v01_validation.md). Source: [nexclash PR #95](https://github.com/bleughb/nexclash/pull/95).
