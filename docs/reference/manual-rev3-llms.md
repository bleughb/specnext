- /api/manual/search?edition=rev3&q=QUERY: search, JSON results with page, heading, URL and a short snippet
- https://zxn.gg/zxnmanualrev3#page=N: the printed page N in the PDF

Page numbers are PDF page numbers.

## Markers

- `<!-- PDF page N -->` starts each page. N is the PDF page number.
- `[?]` marks text that could not be read, or that is missing from the PDF itself.
- `[graphic]` marks a picture, such as a logo in a screenshot, that has no text form.
- `[colour: NAME]` at the start of a table cell gives the colour of that cell, where the colour carries meaning, such as the colour key of the NextREG tables. Anywhere else it is a colour sample printed in the text.
- Tables with merged cells are HTML `<table>` elements with `rowspan` and `colspan`; other tables are Markdown tables.
- Dashes are the dashes of the print; the book sets an en dash (–) in titles, captions, headings and running text.
- Emphasis is as printed: `**bold**`, `*italic*` and `<u>underline</u>`.
- A listing whose text colours the book refers to is an HTML `<pre><code>` block, with each coloured run in `<span data-colour="NAME">`. NAME is a colour name, as for `[colour: NAME]`. Other listings are code blocks.
- A character followed by U+0305 COMBINING OVERLINE is overlined in the book, as in active-low signal names.
- `[^pN-M]` is footnote M, defined on PDF page N.
